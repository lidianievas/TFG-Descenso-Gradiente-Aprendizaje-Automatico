# Fundamentos y aplicaciones del descenso por gradiente en aprendizaje automático

Trabajo Fin de Grado realizado en el **Grado en Matemáticas de la Universidad de Granada**.

## 📌 Descripción

Este proyecto estudia los fundamentos matemáticos y las aplicaciones del **descenso por gradiente**, uno de los principales métodos de optimización utilizados en aprendizaje automático.

El trabajo combina el estudio teórico de los métodos de optimización con diferentes aplicaciones computacionales en problemas de Machine Learning.

## 🧮 Contenidos

* Fundamentos de optimización y convexidad.
* Descenso por gradiente y análisis de convergencia.
* Descenso por gradiente estocástico (SGD) y minibatches.
* Métodos acelerados, incluyendo Nesterov.
* Métodos adaptativos como RMSProp y Adam.
* Aplicación a modelos de regresión lineal y logística.
* Optimización de redes neuronales.
* Experimentos computacionales y análisis de resultados.

## 🛠️ Tecnologías

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* PyTorch
* Jupyter Notebook
